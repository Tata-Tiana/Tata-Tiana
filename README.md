## Избранные проекты

### ИИ-сметчик для строительных проектов

Production-система подготовки смет частных домов по проектной документации.

AI-модель извлекает из PDF структурированные исходные данные, Telegram-бот организует проверку и исправление JSON, Google Sheets используется для контроля объёмов и цен, а детерминированные Python-калькуляторы формируют итоговую смету в Excel.

**Стек:** Python, Telegram Bot API, Google Drive API, Google Sheets API, OpenPyXL, JSON/YAML, systemd

**Репозиторий (production):** https://github.com/Tata-Tiana/ai-estimator-mvp/tree/production

### RAG Assistant для базы знаний компании

AI-ассистент для ответов на вопросы клиентов по локальной базе знаний.  
В проекте есть разбиение документов на чанки, OpenAI embeddings, ChromaDB, память диалога, файловый кеш и оценка качества через RAGAS.

**Стек:** Python, OpenAI API, ChromaDB, RAGAS, CLI  
**Репозиторий:** https://github.com/Tata-Tiana/ragassistent

### Home Services AI Assistant

Мультимодальный Telegram-ассистент для бизнеса в сфере бытовых услуг.  
Отвечает на вопросы по базе знаний компании, работает с текстом, голосом и изображениями, подходит как прототип для автоматизации поддержки клиентов.

**Стек:** Python, Telegram Bot API, OpenAI API, LangChain, ChromaDB, STT, Vision  
**Репозиторий:** https://github.com/Tata-Tiana/home-services-ai-assistant

### AI Competitor Analyzer для Avito

Веб-приложение для анализа объявлений конкурентов в нише ремонта квартир.  
Работает с текстом объявлений, скриншотами, изображениями и страницами конкурентов, после чего формирует структурированный маркетинговый анализ.

**Стек:** Python, FastAPI, OpenAI API, Selenium, Jinja2, HTML/CSS  
**Репозиторий:** https://github.com/Tata-Tiana/avito-analyzer

### VK Product Parser

Пайплайн для подготовки карточек товаров VK Market для сортов петуний и томатов.  
Собирает источники, парсит текст, генерирует структурированные описания через OpenAI, сохраняет данные в Supabase, скачивает фото и готовит публикацию в VK Market.

**Стек:** Python 3.12, OpenAI API, Supabase, VK Market API, Requests, BeautifulSoup, Pydantic  
**Репозиторий:** https://github.com/Tata-Tiana/vkproduct

### Мультимодальный Telegram-ассистент + amoCRM

Telegram-ассистент, который работает с текстом, голосом, изображениями и PDF.  
Умеет анализировать документы, генерировать голосовые ответы, создавать визуалы и переводить лиды по стадиям amoCRM в простом детерминированном сценарии.

**Стек:** Python, OpenAI API, Telegram Bot API, Vision, STT, TTS, Image Generation, amoCRM  
**Статус:** локальный проект, можно публиковать после проверки секретов

### n8n + Pinecone Clients

Локальные Python-клиенты для загрузки `.txt` файлов в production webhook n8n и тестирования семантического поиска через Pinecone.

**Стек:** Python, n8n webhooks, Pinecone, `.env` конфигурация  
**Статус:** локальный проект, можно оформить как integration utility
